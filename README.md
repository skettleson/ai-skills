# ai-skills

Claude skills, one folder each. To use one, copy its folder into your skills directory (for Claude Code, `~/.claude/skills/`), or upload it as a skill in Claude.

| Skill | What it does |
|---|---|
| [layercast-outfit](layercast-outfit/) | Tells you what to wear today, layer by layer, from the hourly forecast where you are. Asks for a short profile on first use. |

Skills that keep personal settings store them outside this repo (Claude's memory, or a gitignored file in your home directory). Nothing personal is committed here.
